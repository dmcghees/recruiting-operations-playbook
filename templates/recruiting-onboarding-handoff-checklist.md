# Recruiting to Onboarding Handoff Checklist

## Purpose

This template provides a consistent process for transitioning an accepted candidate from Recruiting into the onboarding process.

The goal is to make sure required information reaches the correct teams early enough to support Day One readiness.

## Offer Completion

Before initiating handoff:

- [ ] Offer formally accepted
- [ ] Signed documentation confirmed
- [ ] Start date confirmed
- [ ] Job title verified
- [ ] Department verified
- [ ] Manager verified
- [ ] Work location verified
- [ ] Work arrangement verified
- [ ] Recruiting system updated

## Human Resources Handoff

- [ ] Human Resources notified
- [ ] Required employee information transferred
- [ ] Compliance process initiated
- [ ] Payroll process initiated when applicable
- [ ] Benefits process initiated when applicable
- [ ] Required policy process initiated

Sensitive documentation should remain in approved HR or recruiting systems.

## Hiring Manager Handoff

Confirm the manager receives or provides:

- [ ] Confirmed start date
- [ ] Employee contact information through approved process
- [ ] First day expectations
- [ ] Equipment requirements
- [ ] Application requirements
- [ ] Workspace requirements
- [ ] First week schedule
- [ ] Team introduction plan

## Information Technology

- [ ] Laptop request initiated
- [ ] Required equipment identified
- [ ] Email account request initiated
- [ ] Application access identified
- [ ] Shared drive access identified
- [ ] Communication tools identified
- [ ] Delivery or setup plan confirmed

## Workplace Operations

- [ ] Workspace assignment requested
- [ ] Desk setup initiated
- [ ] Monitor requirements confirmed
- [ ] Office supplies prepared
- [ ] Reception notified
- [ ] Arrival instructions prepared
- [ ] Office tour assigned

- [ ] Building badge requested
- [ ] Required access level confirmed
- [ ] Office keys requested when applicable
- [ ] Parking access requested when applicable
- [ ] Building instructions prepared

## Escalation

Escalate when:

- [ ] Required equipment may not arrive before Day One
- [ ] Building access is delayed
- [ ] Required employee information is missing
- [ ] Hiring manager tasks remain incomplete
- [ ] Start date changes
- [ ] Technology setup is blocked
- [ ] Compliance requirements require authorized review

## Candidate Communication

Before Day One, confirm the new employee has received appropriate information regarding:

- [ ] Confirmed start date
- [ ] Arrival time
- [ ] Office or remote instructions
- [ ] Primary contact
- [ ] Required preboarding actions
- [ ] First day expectations when available

## Final Handoff Review

Before Recruiting closes the hiring process:

- [ ] Offer accepted
- [ ] Recruiting system updated
- [ ] HR handoff complete
- [ ] Hiring manager handoff complete
- [ ] Technology request initiated
- [ ] Workplace request initiated when applicable
- [ ] Security request initiated when applicable
- [ ] Outstanding risks assigned
- [ ] New hire has a clear point of contact

## Privacy Reminder

The handoff tracker should contain only information needed to coordinate onboarding.

Do not place sensitive candidate or employee information in general purpose trackers when it belongs in an approved Human Resources or recruiting system.

## Key Takeaway

The handoff is the bridge between recruiting success and employee readiness.

A consistent checklist helps prevent accepted candidates from disappearing into a gap between Recruiting, HR, IT, Workplace Operations, Security, and the hiring manager.
